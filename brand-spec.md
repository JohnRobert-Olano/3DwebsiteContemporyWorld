# Brand Spec — Modern Tech Elegant

Based on user preference for **Modern Minimal** and **Tech / Utility** tones, and the `hero.png` visual reference.

## Palette (OKLch)
- `--bg`:      oklch(12% 0.015 250) /* Deep Obsidian */
- `--surface`: oklch(18% 0.02 250)  /* Dark Slate Surface */
- `--fg`:      oklch(98% 0.005 250) /* Pure White Text */
- `--muted`:   oklch(60% 0.015 250) /* Dimmed Slate */
- `--border`:  oklch(25% 0.02 250)  /* Hairline Border */
- `--accent`:  oklch(60% 0.25 290)  /* Electric Violet (from hero.png) */

## Typography
- **Display:** -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'Inter', system-ui, sans-serif;
- **Body:**    -apple-system, BlinkMacSystemFont, 'SF Pro Text', 'Inter', system-ui, sans-serif;
- **Mono:**    'JetBrains Mono', 'IBM Plex Mono', ui-monospace, Menlo, monospace;

## Layout & Posture
- **Borders:** 1px solid var(--border), subtle 0.5px hairline for tech utility feel.
- **Radii:** 8px for cards, 9999px for status pills/nav.
- **Density:** High information density in overlays, generous whitespace in hero/transitions.
- **Effects:** Glassmorphism (backdrop-blur) for floating panels; subtle violet glows for active states.
- **Hierarchy:** Monospace labels (eyebrows), Bold Sans display, Tight leading.
